# Jeux publiés dans le site gratuit

Place ici uniquement les fichiers que tu as le droit de redistribuer publiquement. Le script Cloudflare copie ces fichiers vers `/games/`; les dossiers locaux `games/` et `repertoire/` ne sont jamais copiés.

Sur l’offre Cloudflare Workers Free, chaque asset doit faire au plus 25 Mio. Dans l’administration GameVault, indique son chemin, par exemple `/games/mon-jeu.zip`. Les fichiers plus volumineux doivent rester sur un hébergeur externe et être ajoutés avec un lien HTTPS direct.
